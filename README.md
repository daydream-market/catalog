# Daydream 社区市集 · 目录

本仓库是 Daydream 互动叙事客户端**社区市集的官方目录**：[`index.json`](./index.json) 聚合所有已收录故事的条目（零服务器——客户端直接拉取本清单，本地搜索过滤）。

## 安装故事

在 Daydream 客户端的「市集」页浏览与安装。所有包均为明文可审计的 `.daydream` 容器，带作者 Ed25519 签名，客户端下载后会独立复验签名与内容完整性。

## 发布你的故事

1. 在 Daydream 客户端导出签名发布包（或按容器格式手工打包签名）；
2. 建一个公开仓库存放：`story.meta.json`、封面、README，包体作为 GitHub Release 附件；
3. 给仓库打上 `daydream-story` topic，或直接向本仓库提 PR 增加 index 条目 / 提 issue 附上仓库地址；
4. 维护者审核（CI 校验签名、哈希与自包含性）后合并即上架。

收录即代表条目出现在所有客户端的市集列表中；下架 = 移除条目（已安装用户不受影响）。

## 治理

侵权、分级不符或恶意内容请提 issue 举报，维护者复核后移除条目。
